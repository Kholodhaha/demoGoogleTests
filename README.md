Описание проекта:

Данный проект реализует автоматизированные тесты для проверки функционала поисковой системы Google с использованием Java, Selenide и JUnit. Цель тестов — проверить корректность работы поиска, пагинации, отображения изображений и других ключевых элементов на странице результатов поиска Google.
В тестах реализованы следующие сценарии:
Открытие главной страницы Google и выполнение поиска по запросу "Selenide Java".
Проверка, что заголовки первых 10 результатов поиска содержат слово "Selenide".
Переход на вторую страницу результатов и проверка, что номер страницы изменился на "2", а результаты отображаются.
Переход на вкладку "Картинки", проверка отображения изображений и открытие увеличенной версии первого изображения.
Проверка отображения основных элементов страницы результатов: поле поиска, кнопка "Поиск в Google" и кнопка "Настройки".
Логирование основных шагов для удобства отладки и анализа выполнения тестов.
Использование явных ожиданий для надежной работы с динамическим контентом Google.

Как запустить тесты:

Клонируйте репозиторий-

git clone <https://github.com/Kholodhaha/demoGoogleTests.git>

Откройте проект в IntelliJ IDEA

Убедитесь, что в проекте настроены зависимости Selenide и JUnit (Gradle).

Запустите тесты из класса SearchAutomationTest как JUnit тесты.

Результаты и логи будут отображены в консоли и в отчетах Selenide.
